``` --- ## Variables à remplacer Pour utiliser ces templates, remplacer les variables suivantes : - `{{OWNER_NAME}}` - Nom du propriétaire de l'équipe - `{{TEAM_NAME}}` - Nom de l'équipe - `{{INVITATION_TOKEN}}` - Token d'invitation unique - `{{CV_COUNT}}` - Nombre de CVs analysés - `{{SUCCESS_COUNT}}` - Nombre de CVs analysés avec succès - `{{AVG_SCORE}}` - Score moyen des CVs - `{{AVG_ATS}}` - Score ATS moyen - `{{DOWNLOAD_URL}}` - URL de téléchargement du CSV - `{{KEY_NAME}}` - Nom de la clé API - `{{CREATED_AT}}` - Date de création - `{{TICKET_ID}}` - ID du ticket de support - `{{TICKET_SUBJECT}}` - Sujet du ticket - `{{CUSTOMER_NAME}}` - Nom du client - `{{SUPPORT_MESSAGE}}` - Message de réponse du support - `{{ORIGINAL_MESSAGE}}` - Message original du client - `{{AGENT_NAME}}` - Nom de l'agent de support --- ## Intégration avec Cloudflare Workers Pour envoyer ces emails depuis les Workers, utiliser un service comme : - **SendGrid** - https://sendgrid.com - **Mailgun** - https://mailgun.com - **Postmark** - https://postmarkapp.com Exemple avec SendGrid : ```javascript async function sendEmail(to, subject, htmlContent) { const response = await fetch('https://api.sendgrid.com/v3/mail/send', { method: 'POST', headers: { 'Authorization': `Bearer ${SENDGRID_API_KEY}`, 'Content-Type': 'application/json' }, body: JSON.stringify({ personalizations: [{ to: [{ email: to }] }], from: { email: 'noreply@swisscv-pro.ch', name: 'SwissCV Pro' }, subject: subject, content: [{ type: 'text/html', value: htmlContent }] }) }); return response.ok; } ```
